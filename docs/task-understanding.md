## About Task (in General)
- Task Name: Radiology Report Generation (RRG) for Chest X-ray (CXR) Image
- Input: CXR Image
- Generated Output:
  - Findings Text
  - Impression Text

## Term Understanding
- Vision Language Model (VLM): A class of models or an architectural level that combines a vision component (an image or video encoder) with a language component (a text encoder or text decoder), trained through a specific method so that these modalities are semantically connected.
- Radiology Report Generation (RRG) is a specific task utilizing a Vision Language Model (VLM) to generate report text from image input.
- Radiology Report Generation (RRG) is solved using a generative-VLM.
- In this context, a generative-VLM is built upon an image encoder, a text decoder, and a fusion/alignment mechanism.
